# 🍽️ SAWA POS — نظام إدارة المطاعم والمقاهي

**SAWA POS** هو نظام متكامل لإدارة نقاط البيع (Point of Sale) والعمليات التشغيلية للمطاعم والمقاهي. تم بناء النظام من الصفر ليغطي دورة العمل اليومية بالكامل، بدءاً من إدارة المنتجات والمستخدمين، مروراً بمعالجة الطلبات وإدارة الورديات، وصولاً إلى لوحة تحكم تحليلية وتقارير تفصيلية.

النظام مصمم ليكون بيئة تشغيلية متكاملة (Enterprise-level Workflow) تربط المبيعات، بالمستخدمين، بالورديات، والمحاسبة المالية، مع الحفاظ على تكامل البيانات (Data Integrity).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

تم بناء وتصميم هذا النظام بالاعتماد على بيئة دوت نت، مع التركيز على أفضل الممارسات البرمجية:
* **اللغة والبيئة:** C# / .NET / Windows Forms
* **قاعدة البيانات:** SQL Server / T-SQL
* **الوصول للبيانات:** ADO.NET (`SqlConnection`, `SqlCommand`, `SqlDataReader`, `DataTable`)
* **المعمارية البرمجية:** 3-Tier Architecture / Object-Oriented Programming (OOP)
* **أدوات مساعدة:** Draw.io (لتصميم قواعد البيانات) / Inno Setup (لإنشاء حزمة التثبيت)

---

## 🏗️ المعمارية البرمجية (Architecture)

يعتمد النظام على **3-Tier Architecture** لضمان قابلية التوسع والصيانة، مع فصل تام للمسؤوليات:
1. **Presentation Layer:** واجهات المستخدم (RTL، متوافقة مع اللغة العربية، بتصميم Dark UI حديث ومريح للعين).
2. **Business Logic Layer:** معالجة قواعد العمل (Business Rules)، التحقق من صحة البيانات، وإدارة حالات الطلبات والورديات.
3. **Data Access Layer:** مسؤولة عن الاتصال المباشر بقاعدة البيانات باستخدام (ADO.NET) وتنفيذ الاستعلامات.

## ✨ الميزات الرئيسية (Core Features)

### 🛒 1. إدارة الطلبات ونقاط البيع (POS & Orders)
* **واجهة كاشير سريعة:** مصممة للاستخدام السريع ودعم شاشات اللمس، تتيح تصفية المنتجات حسب الفئة وإضافتها للطلب بضغطة زر.
* **الأحجام والإضافات (Variants & Add-ons):** دعم كامل لأحجام المنتجات (صغير، وسط، كبير) والإضافات المدفوعة المرتبطة بمنتجات معينة.
* **الطلبات المعلقة:** إمكانية تعليق طلب عميل لخدمة عميل آخر، ثم العودة للطلب المفتوح لاحقاً عبر شاشة إدارة الطلبات.
* **طرق دفع متعددة:** دعم الدفع النقدي (Cash)، البطاقات (Card)، والدفع المزدوج (Split Payment).

### 🕒 2. الرقابة المالية وإدارة الورديات (Shifts & Cash Management)
* **دورة حياة الوردية:** فتح وردية برصيد افتتاحي (Opening Cash)، تسجيل المبيعات/المرتجعات/المصاريف، ثم إغلاق الوردية.
* **حساب العجز والزيادة:** يقوم النظام بحساب النقد المتوقع ومقارنته بالنقد الفعلي الذي يدخله الكاشير لحساب العجز أو الزيادة بدقة.
* **الإغلاق المخفي (Blind Close):** ميزة أمنية تجبر الكاشير على إدخال النقد الفعلي دون معرفة النقد المتوقع من النظام مسبقاً.
* **المصروفات:** ربط المصروفات النثرية بالوردية الحالية لتخصم تلقائياً من النقد المتوقع.

### 🔄 3. المرتجعات والضرائب (Refunds & Taxes)
* **إرجاع جزئي وكلي:** إمكانية إرجاع عنصر واحد من الطلب أو الطلب بالكامل، مع تسجيل العملية مالياً وربطها بالطلب الأصلي دون حذفه.
* **إدارة الضرائب:** دعم كامل لضريبة القيمة المضافة (شاملة السعر أو تضاف على السعر).

### 👥 4. الأمان وإدارة المستخدمين (Security & Authentication)
* **صلاحيات دقيقة (Permissions):** نظام صلاحيات يمنع أي مستخدم من الدخول لشاشات أو تنفيذ عمليات غير مصرح له بها.
* **سجل التدقيق (Audit Trail):** تسجيل دقيق للعمليات الحساسة (من قام بالعملية؟ متى؟ وماذا حدث؟).

---

## 🛡️ هندسة البيانات وسلامتها (Data Integrity)

* **حفظ الأسعار التاريخية (Historical Pricing):** يتم نسخ سعر المنتج لحظة البيع وحفظه داخل فاتورة الطلب لضمان دقة التقارير حتى لو تغير سعر المنتج مستقبلاً.
* **العمليات المترابطة (Atomic Transactions):** استخدام (T-SQL Transactions) في العمليات المالية المعقدة (مثل الدفع والإرجاع) لضمان نجاح العملية بالكامل أو إلغائها بالكامل.
* **الحماية من الثغرات:** استخدام (Parameterized SQL) لمنع هجمات (SQL Injection).
